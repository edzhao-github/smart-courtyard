# 园境远程部署与使用

2026-09-16 已部署到 101.42.42.11。访问 **https://101.42.42.11/dashboard**。使用临时管理员 `admin` 登录，初始密码在本机 `outputs/远程园区访问说明.txt`，不在代码仓库中。

## 日常使用

- 网页直接访问即可，本机无需运行开发服务。后续修改以远程系统为准。
- 本机双击 `连接远程园区.command` 打开网站。
- 双击 `启动远程园区.command` / `停止远程园区.command` 控制远程服务，按提示输入 SSH 密码；脚本不保存服务器密码。
- 网页顶部显示服务器保存状态。出现保存失败、登录过期或版本冲突时会暂停编辑；先下载待保存备份，再刷新核对，不要直接覆盖其他人的修改。
- 原 `localhost:3000` 浏览器数据及导出的迁移源备份仍保留；迁移后的本地编辑不会自动同步到服务器。

## 服务器命令

登录服务器后运行：

```bash
cd /opt/smart-courtyard/app
./deploy/start.sh
./deploy/stop.sh
./deploy/restart.sh
./deploy/status.sh
./deploy/logs.sh
./deploy/backup.sh
./deploy/account.sh
```

`account.sh` 可创建临时账号，输入已有用户名则重置密码并注销该账号旧会话。所有临时账号权限相同，共享一个园区，不是正式的角色权限系统。网站会话有效期 12 小时。

服务使用独立非登录用户 `courtyard`，开机自启，异常退出自动恢复。已有的 3000、8070、8888 等服务未修改。

## 目录与备份

| 目录 | 内容 |
| --- | --- |
| `/opt/smart-courtyard/app` | 应用代码、依赖、生产构建 |
| `/opt/smart-courtyard/data/courtyard.sqlite` | 园区、运营数据、账号、会话、保存日志、最近100个版本 |
| `/opt/smart-courtyard/data/meter` | 电表授权、价格分段与读数历史，权限600 |
| `/opt/smart-courtyard/data/migration-source.json` | 从外部 Chrome 导出的原始备份 |
| `/opt/smart-courtyard/data/tls` | 运行服务使用的 HTTPS 证书 |
| `/opt/smart-courtyard/backups` | 每日03:15以及手动生成的数据库和电表备份 |
| `/opt/smart-courtyard/service.env` | 服务配置，无服务器登录密码 |
| `/etc/letsencrypt` | 证书签发与续期配置 |

SQLite 使用 WAL、事务与乐观版本检查；备份使用 SQLite 在线备份接口。数据库快照与电表文件目前不是同一事务，恢复时应核对计费价格和最后读数。

备份在同一台服务器，不是异地灾备。当前不自动删除备份，正式运营前应设置异地备份、保留周期、容量告警。网页导出包含图纸和运营记录，不包含账号及电表授权；迁移服务器应使用服务器备份。

恢复流程：先停止编辑并备份现状，再停止 `courtyard`；把当前数据库、WAL/SHM及电表目录移到独立留存目录；从选定同一份备份恢复 `courtyard.sqlite` 和 `meter/`，保留现有 `tls/`；将数据所有者设为 `courtyard:courtyard`，启动后核对区域数、账单数及最新读数。恢复旧数据库会恢复旧账号和会话，必须清空 `sessions` 表再启动。不要在进程运行中直接覆盖 SQLite 文件。

## HTTPS 与续期

公网443由认证网关提供 HTTPS，内部应用仅监听127.0.0.1:3181，不能从公网绕过登录。登录密码经过 scrypt 加盐哈希；会话使用 HttpOnly、Secure、SameSite=Strict Cookie。写请求验证来源，登录失败有限流。

采用 Let's Encrypt IP短期证书，首次有效至2026-09-22；`courtyard-certificate.timer` 每日两次检查续期，签发后自动安装并重启正在运行的服务，主动停止的服务不会被续期脚本启动。80端口保留给 Certbot standalone 验证；不要让其他服务长期占用它。请使用完整 `https://` 地址，当前没有HTTP跳转服务。

```bash
systemctl list-timers 'courtyard-*'
journalctl -u courtyard-certificate --no-pager -n 50
/opt/smart-courtyard/certbot/bin/certbot renew --cert-name courtyard-ip --dry-run --no-random-sleep-on-renew
```

IP证书方案依据 [Let's Encrypt 官方说明](https://letsencrypt.org/2026/03/11/shorter-certs-certbot)。域名确定后可切换域名证书和 `COURTYARD_ORIGIN`。

当前运行 Node22.23.1、vinext1.0.0-beta.5。运行时在 `/opt/smart-courtyard/runtime/node`，依赖按锁文件安装。

```bash
cd /opt/smart-courtyard/app
export PATH=/home/lighthouse/.nvm/versions/node/v22.23.1/bin:$PATH
corepack pnpm@12.4.2 install --frozen-lockfile
node --experimental-strip-types --test tests/*.test.mjs
node node_modules/typescript/bin/tsc --noEmit

./deploy/restart.sh
```
