# 园境 · 智慧园区平面图编辑器

基于 HTML / SVG、React 与 TypeScript 的二维园区编辑器。SVG 是可交互的矢量图，不依赖鸟瞰照片。

## 使用

- 结构线：点击起点，再点击终点；Shift 约束水平 / 垂直。
- 房间、大棚区、露天区、大门：拖拽绘制；Shift 绘制正方形。
- 选择工具：拖拽移动，右下角控制点调整尺寸；属性面板可输入精确尺寸、位置和旋转角度。
- 复制后拖动可快速排列商铺。支持删除、撤销、重做、平移、缩放、适应全部图形。
- 修改属性后离开输入框生效。坐标和尺寸的单位均为米。
- 自动保存仅保留当前浏览器的一张图。新建、载入示例、导入会替换当前图，可撤销恢复。请定期导出 JSON 备份。
- JSON 导出包含所有业务属性，可以再次导入。SVG 导出是当前视图的独立矢量图，建议先点“适应全部图形”。
- 参考示例借鉴参考图中的商铺、公共建筑和开放区域，尺寸与布局均为示意，不是测绘结果。

## 后续系统集成

数据结构定义位于 `lib/plan.ts`，图纸为 `{schemaVersion:1, name, unit:'m', elements:Space[]}`。
每个空间有稳定 `id`、类型 `kind`、名称、几何和业务属性；后续可通过 `id` 关联房源、租赁合同、设备、水电表与账单。

坐标：X 向右、Y 向下。矩形 `(x,y)` 是未旋转左上角，宽高为米，`rotation` 绕该点顺时针旋转。结构线起点是 `(x,y)`，终点是 `(x+width,y+height)`，旋转同样绕起点应用。

类型：`room` 房间、`greenhouse` 大棚、`outdoor` 露天区、`gate` 大门、`line` 结构线。

费用：`rent` 为整个区域每月租金（元/月），`waterRate` 为元/m³，`electricityRate` 为元/kWh；0 表示尚未设置或免费，由业务方确认。`floor` 是楼层数，面积显示为占地宽×长，不自动乘楼层。面积合计未消除区域重叠。

当前没有后端同步、账户权限、计费或真实地图坐标；对接时应在后端再次验证 JSON，并使用数据库保存。浏览器支持 WebMCP 时注册 `read_park_plan` 和 `select_park_space`；当前环境未进行 WebMCP 运行验证。

## 开发

安装依赖后 `pnpm run dev`，构建 `pnpm run build`。类型检查 `pnpm exec tsc --noEmit`。数据测试使用 Node 22.13+：`node --experimental-strip-types --test tests/plan.test.mjs`。

## 园区管理驾驶舱（/dashboard）

驾驶舱读取同一来源浏览器内的现有图纸，以区域稳定编号关联手动台账，不改动绘制的几何。

- 地图视角：业态、当前出租状态、配置月租金、当月应收水费、电费和水电管线。
- 账单：每区域每月一条记录，可录用量、租金/水/电应收及实收、缴费截止日；重复保存更新该条。
- 停车：每日期一条全园区日报，记录当日停车实收和可选收费车次，不包含充电收入。
- 管线：管理者手动标注路线。管线几何独立于房间的通水/通电状态；移动房间不会自动修改管线路径。
- 所有指标只依据已录入数值，不推算缺失月份、日期及区域。空白为未录入，0 为确认零。
- 待收款只统计同时填写应收及实收的费用项。实收不允许大于应收，预收款未纳入当前模型。
- 出租率按 room/greenhouse/outdoor 类型数量计算。自用、维修、待规划仍在分母中，当前不是可出租库存口径；页面标注为全部可租类型区域。
- 趋势图按所选月份之前共六个月汇总水、电应收。排名是金额高低，不是设备异常判断。
- 数据只存当前浏览器，不是多用户云端系统，也未接实时设备、支付或财务系统。运营备份 JSON 包含图纸、月度账单、停车日报与管线。切换浏览器须导入备份。
- 只有当前图纸已有区域编号对应的台账参与汇总；其他图纸或已删除区域的台账保留在备份中，不混入汇总。

数据定义及校验位于 `lib/operations.ts`。金额以人民币元计，用量水 m³、电 kWh；尚不计算向供应商支付的水电成本及利润。后续接后端时需加入分园区权限、审计日志、数据库事务和接口鉴权，当前无登录版本不提供共享的经营账本。

驾驶舱在支持 WebMCP 的浏览器中注册只读 `read_park_operating_summary`，按月份读取本地手动台账汇总。当前工具环境未进行 WebMCP 运行验证。

## 本地独立运行（无需网站域名或登录）

双击项目中的 `启动园区管理.command`，保持启动的终端窗口运行。在普通浏览器访问：

- 驾驶舱：http://localhost:3000/dashboard
- 绘图工具：http://localhost:3000/

该启动入口设置 `COURTYARD_LOCAL=1`，绕过 Sites 托管中间件和 Cloudflare 运行时，只启动本地 Vite/Vinext 服务。页面切换使用普通相对链接。端口固定为3000，避免端口变化导致浏览器内图纸看似丢失；若端口占用，关闭之前启动的服务再启动，勿随意更换地址。

本地服务需要保持运行，关闭终端或按 Ctrl+C 会停止。此入口是本机开发运行方式，不设置开机自启。现有依赖已安装，本地使用不需要重新上传或发布。

线上域名和 localhost 的浏览器存储相互隔离。先在原线上驾驶舱点击“备份”，再在本地驾驶舱点击“导入图纸 / 备份”，即可迁移图纸、月度账单、停车日报和管线；只有图纸时也可导入图纸 JSON。请始终使用 localhost:3000，127.0.0.1 和不同浏览器不会共享此本地存储。
